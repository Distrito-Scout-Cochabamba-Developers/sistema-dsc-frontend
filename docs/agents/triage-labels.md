# Triage labels

Use these Azure DevOps work item tags for the canonical triage roles.

| Role | Tag | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer review. |
| `needs-info` | `needs-info` | Waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be addressed. |
