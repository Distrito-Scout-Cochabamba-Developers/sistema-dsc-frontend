# Architecture Decision Records (ADR)

Registra aquí decisiones que alteren arquitectura, dependencias transversales o excepciones al contrato en `agents.md`.

## Convención de nombres

`NNNN-titulo-en-kebab-case.md` (ej. `0001-usar-signals-para-estado-local.md`)

## Plantilla mínima

```markdown
# NNNN. Título

- Estado: Proposed | Accepted | Deprecated
- Fecha: YYYY-MM-DD
- Decisores: …

## Contexto

## Decisión

## Consecuencias
```
