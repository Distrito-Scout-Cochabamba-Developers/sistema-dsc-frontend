Consideraciones de uso

  • Primary: utilizar para botones principales, enlaces y elementos destacados.
  • Institutional navy: utilizar en encabezados, navegación y elementos de identidad institucional.
  • Surface: utilizar como fondo de páginas, secciones y superficies de contenido.
  • Semantic: utilizar para comunicar estados, siempre acompañado de texto o iconografía.
